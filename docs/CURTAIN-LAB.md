## 本轮验收目标

- 仅新增开发路由 `/curtain-lab`：单窗墙、窗框、薄纱对开帘、柔光。
- 先检查关闭/半开/全开静态状态，再开启连续运动；支持立即定位、动画切换、中途反向、滑块、微风开关、正面/侧面观察。
- 褶皱分段聚拢，保留底摆滞后和两侧帘束；复用网格，不在每帧重建。
- 使用 MSAA alpha-to-coverage 近似纱线透光，参与深度测试，避免透明对象排序依赖；无 MSAA 时降级为 alpha hash（有颗粒，尚未验收该分支）。不是光学透射或布料物理仿真。
- 预览控制只改变本页渲染参数，不创建业务设备，不读写 useScene、项目、账号或数据库。后续接入须走既有工具层与 useScene。
- 不修改 Pascal 包，不迁移架构，不替换现有窗帘，不改旧场景/碰撞补丁，不部署。
