## 1. 必须搞定（上线前 must-do）

### 1.1 邮件服务接通（半天）

**为什么必须**：朋友忘记密码的概率是 100%。Better Auth 的密码重置功能代码已经写好，但**没接邮件服务**，意味着重置邮件发不出去。`.env.example` 里有 `RESEND_API_KEY` 但没填值。

**怎么办**：
- 注册 [Resend](https://resend.com)（免费档每月 3000 封够内测）
- 国内邮箱（QQ / 网易）经常被 Resend 邮件挡，建议**朋友测试用 Gmail 或公司邮箱**
- 把 API key 填到生产环境变量
- 在 Better Auth 配置里接入 sendEmail 函数

**验证**：自己用一个新邮箱注册 → 退出 → 点"忘记密码" → 收到重置邮件 → 改密码成功。

### 1.2 域名 + 备案 + HTTPS（关键岔路口）

**这是最容易踩雷的地方，请仔细看：**

仓库 CLAUDE.md 提到 `studio.vilhil.cn` —— `.cn` 域名在中国大陆部署**必须 ICP 备案**，备案要 2-3 周时间，需要营业执照或个人身份证。

**三个选项，二选一**：

| 方案 | 部署位置 | 域名 | 备案要求 | 速度 | 备案时间 |
|------|---------|------|---------|------|---------|
| A | 境内（阿里云/腾讯云） | studio.vilhil.cn | **必须** | 国内快 | 2-3 周 |
| B | 境外（Vercel） | studio.vilhil.cn | 不需要 | 国内偏慢 | 0 |
| C | 境外（Vercel） | studio.vilhil.com | 不需要 | 国内偏慢 | 0 |

**给非开发者的建议**：先用 **方案 B 或 C** 跑朋友内测，速度差一点能忍。等正式上线再考虑备案。**不要因为备案卡 2-3 周不动**。

**部署平台推荐**：
- **Vercel**（最适合 Next.js，零配置部署，免费档够内测）
- 操作流程：github 仓库连 Vercel → 设环境变量 → 自动部署
- 仓库里没有 `vercel.json`，但 Next.js 项目 Vercel 默认就识别

**HTTPS**：Vercel 自动配，自动续期，不用管。

### 1.3 ICP 备案（如果走方案 A，否则跳过）

只有用 `.cn` 域名 + 国内服务器才需要。流程：
1. 在阿里云/腾讯云买服务器（一年起）
2. 提交备案材料（身份证 + 域名 + 服务器订单）
3. 等管局审核，2-3 周
4. 备案号挂到网站底部

**强烈建议先走方案 B（Vercel + .cn）跳过备案**，备案不影响 Vercel 国外部署。**注意**：用 Vercel 部署 .cn 域名访问国内会偏慢，但能用。

### 1.4 生产环境数据备份验证（30 分钟）

Supabase 默认有每日备份，但你要：
1. 登录 Supabase 控制台 → 你的项目 → Database → Backups
2. **确认看到至少 1 个 backup 已生成**
3. **试着从备份恢复一次**（恢复到一个新项目，不影响主库），确保流程能跑通
4. 截图存档，万一出事知道怎么找

**很多人备份开了，但从没试过恢复，真出事懵。**

### 1.5 Uptime 监控（10 分钟）

朋友半夜打不开网站，你睡到天亮才知道，这种事用免费工具就能避免。

**怎么办**：
- 注册 [UptimeRobot](https://uptimerobot.com)（免费档 50 个监控点）
- 添加监控：
  - `https://studio.vilhil.cn/`（首页）
  - `https://studio.vilhil.cn/api/health`（健康检查）
- 通知方式：邮件 + Slack/微信（Webhook）
- 间隔：5 分钟

**5 分钟配完。** 出事手机会震。

### 1.6 域名 / SSL 续期提醒（5 分钟）

**血泪教训**：很多创业项目第二年 12 月被域名过期搞挂，因为续费邮件被 Spam folder 挡。

**怎么办**：
- 在域名注册商（万网/Namecheap）开**自动续费**
- 把 SSL（Let's Encrypt）续期交给 Vercel 自动管理
- 在你自己日历加一个**每年提前 30 天的提醒**

### 1.7 朋友内测的反馈通道（半天）

**问题**：朋友遇到问题，只能找你微信。但你不在线/睡觉时，反馈丢了。

**最简方案**（够内测）：
- 建一个**微信群**，名字叫"VilHil Studio 内测群"
- 群公告写"遇到问题截图发群里 + @atom"
- 把群二维码贴到编辑器右下角的悬浮按钮里

**稍微正式点**（推荐）：
- 用 [飞书群](https://www.feishu.cn) 或 [Discord](https://discord.com) 建社区
- 编辑器右下角放"反馈"按钮 → 弹窗（包含群链接 + 邮箱 + 文字反馈输入框）
- 反馈直接进 Sentry 或飞书机器人

**改 1 处文件**：`apps/editor/app/error.tsx` 加一个"联系支持"按钮（链到群 / 邮箱）。错误页是用户最焦虑的时候，必须给他出口。

### 1.8 财务预算（10 分钟）

内测期间每月大概要花多少钱（人民币）：

| 项 | 服务 | 月费 |
|---|------|------|
| 部署 | Vercel Hobby | 0（10 个朋友够） |
| 数据库 | Supabase Free | 0（500MB 够内测） |
| 错误监控 | Sentry Developer | 0（5K events 够） |
| Rate limit | Upstash Redis Free | 0 |
| 邮件 | Resend Free | 0（3000 封） |
| 监控 | UptimeRobot Free | 0 |
| 域名续费 | .cn 域名 | ~30/年 |
| **小计** | | **0/月**（域名一次性 30/年）|

**好消息**：内测全免费档够用。等用户超过 100 人或需要更稳定 SLA 再升级。

**预算红线**：当月任何一项超过 ¥100 就要停下来评估是不是被刷了。

## 2. 强烈建议做（上线第一周）

### 2.1 示例项目 / 新手引导（半天）

**问题**：朋友登录后看到空白的 `/projects` 页，按"新建项目"进入空房间，**完全不知道下一步**。

**最简方案**：
- 建一个"客厅样板间"项目（4 面墙 + 沙发 + 3 盏筒灯 + 1 个面板），导出 JSON
- 新用户注册后自动 fork 这个项目到他的账号下
- 第一次进编辑器有个 onboarding tooltip："拖动左侧物品到房间"

**改 2 处**：
- `db/seed.ts` 加 sample project 数据
- `app/api/auth/signup` 后续逻辑里 fork sample 给新用户

### 2.2 用户支持邮箱改对（5 分钟）

当前 `/privacy` 和 `/terms` 页面里写的是 `support@pascal.app`，应该是 `support@vilhil.cn`（或你实际的邮箱）。**朋友写邮件去 pascal.app 不会有人回**。

**怎么办**：搜全仓 `pascal.app` 替换成你的邮箱。

### 2.3 简单的 Analytics（1 小时）

不是为了营销，是为了知道**朋友真用了多少**。免费选项：

- [Plausible](https://plausible.io)（30 天试用，¥60/月起）
- [Umami](https://umami.is)（开源自托管，免费）
- 已经有的 Vercel Analytics（部署到 Vercel 自动开）

**建议直接用 Vercel Analytics**，零配置，能看 PV/UV/页面访问。

### 2.4 简单的用户使用文档（1 天）

写个 `/help` 页面或 `docs.vilhil.cn`，包含：
- 怎么注册
- 怎么画第一个房间
- 怎么放灯
- 怎么生成分享链接
- 常见问题（5-10 条）
- 截图 + 视频（视频用录屏工具录 5 段，每段 30 秒）

**改 1 处**：`apps/editor/app/help/page.tsx` 新建。

### 2.5 404 页面（30 分钟）

新建 `apps/editor/app/not-found.tsx`，写"页面不存在 + 返回首页 + 联系支持"。当前没有，访问错误链接看到 Next.js 默认页面，不专业。


## 6. 我看到的最大三个非技术风险

1. **域名 / 备案路线没想清楚** — 如果你想走方案 A（国内部署 + 备案），等 2-3 周。强烈建议先 B 或 C 跑起来。
2. **没有反馈通道** — 朋友报 bug 没地方说，挫败感会很快让他们放弃测试。微信群 30 分钟搞定。
3. **没有示例项目** — 朋友登录后看着空白屏幕，**不知道从哪开始**。这个不修，10 个朋友里 6 个会在 5 分钟内放弃。
