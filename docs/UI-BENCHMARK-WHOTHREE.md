# UI 对标基准：WhoThree Floorplan Demo

> 目的：不是照抄（not fork），而是提取可复用的规范。  
> 对标目标站点：`https://floorplan-demo.whothree.space/`

---

## 1. 对标结论（可直接执行）

WhoThree 的“高级感”来自 **克制和一致**，不是复杂特效：

1. 变化只在 token 层，不改布局骨架。
2. 激活态只给一个强信号（边框/底色），不叠加多个装饰。
3. 按钮尺寸和圆角分档非常稳定，几乎无随机值。
4. 图标优先，文字仅保留关键信息。
5. 所有阴影都轻量，主要靠留白和分组建立层级。

---

## 2. 抓到的真实样式参数（day 模式）

### 2.1 工具按钮（左侧）

1. 尺寸：`67x65`
2. 圆角：`18px`（`rounded-2xl`）
3. 字号：`10px`，字重 `500`
4. 激活态：蓝色边框 + 浅蓝底 + 蓝色文字
5. 阴影：`0 14px 28px rgba(37,99,235,0.12)`（只在激活态明显）

### 2.2 顶部圆形功能按钮

1. 尺寸：`44x44`（部分主按钮 `48x48`）
2. 形状：`rounded-full`
3. 边框：`1px` 浅灰
4. 阴影：`0 10px 24px rgba(15,23,42,0.12)`（主按钮为 `0 16px 36px rgba(15,23,42,0.10)`）
5. 交互：`hover scale 1.04`，不使用多层发光

### 2.3 底部主题圆点

1. 尺寸：`32x32`
2. 圆角：`full`
3. 边框：浅色 `1px`
4. 阴影：`0 8px 18px rgba(15,23,42,0.12)`
5. 选中态：单圈 ring，避免多层高光

---

## 3. 昼夜与主题策略（信息架构层）

### 3.1 主题（白/蓝/绿/紫）

1. 主要影响强调色（selected/icon/accent）。
2. 不重排布局，不改变控件尺寸体系。
3. 风格差异“可感知但不喧宾夺主”。

### 3.2 昼夜（day/night）

1. 是主视觉模式切换（背景与面板明暗反转）。
2. 图标与边框对比度同步切换，保证可读性。
3. 交互手势和组件结构不变。

---

## 4. 对 VilHil 的落地规范（执行版）

> 适用于：`apps/editor/app/proposal-demo` 及后续展示页。

1. 组件分档固定：
   - Icon button: `44x44`
   - Primary icon button: `48x48`
   - Theme dot: `32x32`
2. 圆角分档固定：
   - 大卡片 `16~18px`
   - 圆形控件 `full`
3. 激活态规则：
   - 只允许一个主信号（边框或底色二选一为主）
   - 禁止叠加多层 ring + glow + inner-glow
4. 阴影规则：
   - 默认 `0 10px 24px rgba(15,23,42,0.12)`
   - 强调控件可用 `0 14px 28px rgba(37,99,235,0.12)`
5. 文字密度：
   - 工具栏 `10px/500`
   - 辅助信息 `10-11px`，正文不小于 `12px`
6. 风格切换逻辑：
   - 先切昼夜（主模式）
   - 再切主题（强调色层）
   - 不允许在主题切换时改布局结构
